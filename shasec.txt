Tester vite en ligne de commande :

  # 1) login -> récupère le token
  TOKEN=$(curl -s -X POST http://localhost:8000/api/v1/auth/login \
    -H 'Content-Type: application/json' \
    -d '{"email":"admin@kaanari.com","password":"ShaSec#Admin2026!"}' \
    | python -c "import sys,json;print(json.load(sys.stdin)['data']['access_token'])")

  # 2) quick scan (passif) d'une cible autorisée
  curl -s -X POST http://localhost:8000/api/v1/scans/quick \
    -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
    -d '{"url":"https://kortex.sbs","type":"website","allow_active_exploitation":false}'

  # 3) findings du scan
  curl -s http://localhost:8000/api/v1/scans/<ID>/findings -H "Authorization: Bearer $TOKEN"

Réinitialiser le mot de passe admin (dans le conteneur api) :
  docker compose exec api python -m backend.cli create-admin --email admin@kaanari.com --password "<nouveau>"
  (idempotent : ne recrée pas un compte existant — utiliser un email neuf pour repartir de zéro)
